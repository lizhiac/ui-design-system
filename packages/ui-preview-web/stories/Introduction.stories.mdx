# 跨端设计系统

> 一套 Token + 组件，跨小程序 / Web / App / PC 复用。

## 架构

```
packages/
├── tokens/         Style Dictionary 源 + 多端产物
├── ui-mp/          微信小程序组件库 (TS + WXML + WXSS)
└── ui-preview-web/ Web 预览层 + Storybook 文档
```

## 使用方式

### 小程序项目

```bash
pnpm add @ui/ui-mp
```

```json
// app.json
{
  "usingComponents": {
    "ui-button": "@ui/ui-mp/button",
    "ui-icon":   "@ui/ui-mp/icon"
  }
}
```

```html
<ui-button type="primary" size="lg">查看图纸</ui-button>
```

并在 `app.wxss` 引入 token 产物：`@import '@ui/tokens/dist/miniprogram/variables.wxss';`

### Token 修改

只改 `packages/tokens/tokens/*.json` → `pnpm tokens:build` → 所有端产物同步更新。

## 设计规范要点

- 标准黑：`#1D2129`
- 主品牌色：`#FFD933`（胶囊按钮）
- 圆角：胶囊按钮 `44rpx`
- 字号基准：30rpx（按钮）/ 28rpx（正文）
